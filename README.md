# ⚽ The Project I Spend Way Too Much Time On

## [Footy — Full-Stack Football Simulation Platform](https://github.com/x-Kevin-Paul-x/Footy)

What started as:

> "Wouldn't it be cool if I simulated football matches?"

somehow became a full-stack football simulation platform built around **Google Research Football**.

It now includes simulation, APIs, persistent data, analytics, seasons, replay generation and a web interface.

### Some numbers because numbers make projects look serious:

- ⚽ Full **11v11 Google Research Football** matches
- 🤖 Neural policies controlling simulated players
- ⚡ Around **10× real-time simulation throughput** in benchmarking
- 🧪 **95 passing backend tests**
- 🔌 **63 FastAPI routes**
- 🗄️ SQLAlchemy relational data layer
- 📡 REST + WebSocket communication
- 🎥 2D + 3D replay pipelines
- ⚛️ React + TypeScript frontend
- 📊 ~33k lines across Python and TypeScript

### Stack

`Python` `FastAPI` `PyTorch` `Google Research Football`  
`SQLAlchemy` `React` `TypeScript` `WebSockets` `FFmpeg`

👉 [Explore Footy](https://github.com/x-Kevin-Paul-x/Footy)
